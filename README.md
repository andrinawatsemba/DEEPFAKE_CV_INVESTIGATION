# Deepfake Computer Vison Investigation

## Overview
This research investigates real and AI-generated images, including the effects of image sharing and compression through WhatsApp, in a Ugandan context.

## Research Objectives
- Collect and document suitable real and AI-generated image datasets.
- Investigate image transformations introduced by WhatsApp sharing.
- Audit dataset quality, duplicates, and potential data leakage.
- Evaluate whether image properties create shortcuts that could bias deepfake detection.

## Project Structure
- `docs/` :Dataset documentation, collection protocols, and licences.
- `notebooks/` : Data sampling and audit notebooks.
- `src/` : Reusable processing and analysis code.
- `reports/` : Aggregate statistics, visualizations, and audit results.

## Data Management
Raw images and large datasets are stored separately from the GitHub repository. Only data that is permitted for sharing will be published.

## Collaboration
Contributors should document dataset sources, record processing decisions, and avoid committing sensitive data, credentials, or restricted dataset files.
