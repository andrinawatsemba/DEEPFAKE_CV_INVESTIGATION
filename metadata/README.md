# metadata/

Small CSV files that describe images. **No images are stored here.**

* `public_<source>_<CODE>.csv` : one per member and source, produced by notebook 01. Upload yours here after the FULL pull.
* `campus_labels_<CODE>.csv`, `campus_log.csv`, `campus_manifest.csv` : the UCU Mukono campus set (notebook 04).
  These contain no names. Consent records are kept privately, never here.
